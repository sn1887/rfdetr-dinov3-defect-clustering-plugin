## 0.1.0 — 2026-07-29

### Added

- Complete standalone Dataiku DSS plugin with one `cluster-defect-instances` recipe.
- RF-DETR 1.5.2 safe state-dictionary adapter and offline timm DINOv3 ViT-B/16 safetensors adapter.
- INSID3-derived positional debiasing and fractional box-prototype pooling.
- Content-addressed detector/embedding caches and versioned run bundles.
- Spherical k-means, canonical cluster IDs, representative ranks, and review order.
- Fixed review dataset schema and native Dataiku object-detection prelabels.
- Local/remote managed-folder support, partial failures, OOM recovery, checksums, and provenance.
- Unit tests, synthetic integration tests, environment qualification, artifact validation, audit, and packaging scripts.
- Deployment, security, labeling, quality-audit, and development documentation.
